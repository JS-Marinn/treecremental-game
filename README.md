# Treecremental

A 2D pixel-art incremental game built in Godot 4.7. Deploy lumberjack crews across 9 tree species in 3 distinct biomes, process timber through water-powered sawmills and brick charcoal kilns, cultivate a symbiotic underground mycelium network and canopy aviary, and ascend through the Heartwood Sap constellation.

## Project Status

- **Current Stage**: `planning` (Architectural design, mathematical balance modeling, itemized upgrade specification, and UI mockup phase).
- **Target Playthrough Duration**: ~3.0 hours for main campaign completion (*The Great Felling*); ~4.0 hours for 100% achievement and upgrade completion.
- **Session Model**: Active/semi-idle continuous session. Zero offline progression mechanics.
